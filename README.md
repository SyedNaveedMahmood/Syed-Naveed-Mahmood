## Research Experience

### Undergraduate Thesis Researcher · BRAC University
**2025 - 2026**

#### Representation-Aware Unlearning via Activation Signatures: From Suppression to Knowledge-Signature Erasure
Submitted to **ACL Rolling Review, May 2026 Cycle**

This work develops the **Knowledge Immunization Framework (KIF)**, a representation-aware LLM unlearning pipeline designed to distinguish actual knowledge-signature reduction from surface behavioral suppression.

**Research Contributions**
- Designed a three-stage unlearning pipeline: **probe → suppress → distill**
- Built activation-signature mining mechanisms over hidden-state representations
- Used probing classifiers to identify target-knowledge traces inside LLM activations
- Developed signature-guided suppression mechanisms through intervention capsules
- Implemented a PEFT-based self-healing unlearning loop using **LoRA adapters**
- Combined **DPO**, **unlikelihood training**, **name-token unlikelihood**, **KL regularization**, and **EWC-style utility preservation**
- Introduced a dual-metric evaluation framework:
  - **SMR:** Subject Mention Rate
  - **EL10:** Extraction Likelihood at 10 autoregressive steps
- Evaluated forgetting quality while tracking utility drift and representation-level signals

**Repository:**  
[Representation-Aware-Unlearning-via-Activation-Signatures-KIF](https://github.com/SyedNaveedMahmood/Representation-Aware-Unlearning-via-Activation-Signatures-KIF)

### Deep Learning Researcher · Sleep Stage Classification Project
**2024 - 2025**

#### GradG-AttnSleep: Dual-Mode GradCAM for Interpretable Sleep Staging with an Attention-Based CNN

This project developed **GradG-AttnSleep**, an attention-based CNN architecture with branch-aware **Dual-Mode GradCAM** for interpretable automated sleep stage classification from EEG signals.

**Highlights**
- Developed an interpretable deep learning pipeline for EEG sleep stage classification
- Used branch-aware GradCAM to explain model behavior across sleep-stage decision pathways
- Evaluated on **Sleep-EDF-20** using LOSO evaluation
- Achieved **87.33% accuracy**
- Published at **IEEE ICITEE 2025**
- Indexed in **Scopus**
